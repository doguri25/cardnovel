# 더 나은 카드 그림: Gemini 앱 도우미 · 연출 정리 · 한국인 인물

날짜: 2026-11-22 · 상태: 사용자 승인(대화에서 1·3번 방식 선택, "더 고도화할 방법이 있으면 넣고 진행")

## 왜

지금 그림 AI(Canva AI, Gemini 이미지, GPT 이미지)로 그린 카드가 세 가지 모두 아쉽다.

1. 그림 솜씨 자체
2. 장면이 카드 글과 안 맞음
3. 장마다 인물이 달라짐

여기에 더해 Canva AI는 인물을 한국인이 아닌 서양인으로 그린다. 사용자는 추가 비용 없는 방법을 원한다. 사용자는 Gemini Pro 구독(Gemini 앱에서 최신 그림 모델로 하루 100장 안팎)을 쓰고 있고, 컴퓨터는 맥북 네오(A18 Pro, 메모리 8GB)라 자기 컴퓨터에서 그림 모델을 돌리기는 어렵다.

## 목표

- 추가 비용 없이 최고 수준의 그림 모델(Gemini 앱의 Nano Banana Pro)로 20장을 그리게 돕는다.
- 모든 그림 AI에서 인물을 한국인·현대 한국 배경으로 그리게 한다(바꿀 수 있게).
- 참고 그림을 못 받는 Canva AI에서도 장면 맞추기와 인물 유지를 지금보다 낫게 한다.

## 하지 않는 것

- 새 유료 그림 서비스(fal.ai 등) 연결. 사용자가 무료를 원해 이번엔 뺀다.
- 사용자 컴퓨터에서 그림 모델 돌리기(맥북 네오 사양 부족), 블렌더.
- Gemini 앱 자동 조작(앱을 대신 클릭·다운로드하는 것). 구글 앱을 자동화할 공식 방법이 없고 약관상 위험하다.

## 실패로 볼 것

- 한국인 기본값이 사극·판타지·외국 배경 이야기까지 억지로 한국으로 바꿔 버림 → 칸으로 바꿀 수 있어야 한다.
- 도우미가 손이 너무 많이 가서 안 쓰게 됨 → 지시문 복사 한 번, 그림 붙여넣기 한 번이 카드 한 장의 전부여야 한다.
- 연출 정리가 작가가 고친 장면·인물 설정을 덮어씀.

## 고려한 방식

| 방식 | 장점 | 단점 | 결정 |
| --- | --- | --- | --- |
| 1. Gemini 앱 도우미(반자동) | 구독 안에서 무료, 최고 모델, 한 대화 안에서 인물이 이어짐, 폰에서도 됨 | 복사·붙여넣기를 사람이 함 | **채택** |
| 2. 구독 크레딧($10/월)으로 앱 안 Gemini 자동 그리기 | 손이 덜 감 | 결제 계정 연결·선충전 필요할 수 있고 API 적용 여부가 불확실 | 이번엔 안 함 |
| 3. 그리는 과정 고치기(모든 그림 AI, Canva 포함) | 무료, 모든 그림 AI에 효과 | Canva는 참고 그림을 못 받아 인물 유지에 한계 | **채택** |
| 새 유료 모델(fal.ai Seedream·FLUX) | 품질·인물 유지 최고 수준 | 유료 | 무료 요청으로 제외 |
| 내 컴퓨터에서 그리기(ComfyUI) | 무료·무제한 | 맥북 네오 8GB로는 너무 느림 | 제외 |

## 설계

### A. 인물·배경 (모든 그림 AI 공통)

- `ArtStyle`에 `world: string`(인물·배경)을 둔다. 기본값 `"한국인 · 현대 한국"`. 예전 작품은 불러올 때 기본값을 채운다(`normalizeWork`).
- 「그림체 자세히 고치기」에 '인물·배경' 칸(한국어로 적어도 됨). 비우면 지정하지 않음.
- 그림 지시문에 영어로 넣는다: `World: <world>. People are <...> unless the story says otherwise.` 구체적으로는 world를 그대로 넣고, 기본값일 때는 `All people are Korean, with East Asian features; the setting is contemporary South Korea (streets, homes, objects), with no readable signage.`로 바꿔 넣는다.
  - 대상: `imagePrompt`(Gemini·GPT), `canvaPrompt`(Canva AI), `characterSheetPrompt`, `svgPrompt`(Claude SVG), Gemini 앱 지시문.
- 글 AI가 인물 생김새(`characters`)를 쓸 때 world를 따르게 한다("이름: 한국인 40대 남성, …"). 카드 구성 지시와 연출 정리 지시 모두.

### B. 연출 정리 (그리는 과정 고치기)

- 글 AI 요청 한 번으로 이야기 전체를 읽고 다음을 돌려받는다.
  - `characters`: 인물마다 고정 생김새(world 반영: 나이·얼굴·머리·체형·기본 옷차림), `이름: …` 형식.
  - 카드마다 `scene`: 앞뒤 카드와 이어지게(같은 장소는 같은 모습, 같은 시간대·날씨, 장면별 옷차림), 기존 SCENE_RULE 그대로.
- 결과 적용: 장면은 카드마다 `scene`·`sceneFor`를 바꾼다. 인물은 작가가 직접 고친 적이 없을 때만 바꾸고(`style.charactersByWriter` 표시), 고친 적이 있으면 그 설정을 지키며 장면만 바꾼다.
- 실행: 「그림체」 상자에 「연출 정리」 버튼. Gemini 앱 도우미를 열 때와 「모든 그림 그리기」 확인 창에서 "연출을 먼저 정리할까요?"를 권한다(이미 정리했고 글이 그대로면 묻지 않음: `style.directedFor = textSig(work)`).
- 실패하면 기존 장면으로 그대로 그린다.

### C. 카드 후보 (모든 그림 AI)

- 지금 표지에만 있는 「후보 3장」을 모든 그림 카드로 넓힌다. 표지는 지금 구도 3가지, 본문은 2가지(인물 표정이 보이는 미디엄 샷 / 장소와 분위기가 보이는 와이드 샷).
- 미리보기는 완성 카드 모습으로 보여 주고, 고르면 그 카드에 들어간다. Canva AI는 비용 대신 사용량 차감 안내.

### D. Gemini 앱 도우미

창(모달) 하나:

```
[Gemini 앱으로 그리기]                         [닫기]
① 준비
   - (연출을 정리하지 않았으면) [연출 먼저 정리하기]
   - [첫 메시지 복사] → Gemini 새 대화에 붙여넣기 (그림체·인물·비율·규칙 + 인물 기준 그림 먼저 그리기)
   - [인물 기준 그림 받기] (있으면, Gemini에 같이 올림)
② 카드별 지시문 (그림 없는 카드부터)
   01 표지   [복사]  [붙여넣기] ✔
   02        [복사]  [붙여넣기]
   …
③ [그린 그림 한꺼번에 올리기] → 순서 확인 화면(끌어서 바꾸기·빼기) → [카드에 넣기]
```

- 첫 메시지(한국어): 이 대화에서 카드소설 그림 N장을 차례로 그린다, 그림체(style.prompt), 인물·배경(world), 인물 설정(characters), 규칙(글자·말풍선·워터마크 없음, 인물 얼굴·옷 유지, 그림 한 장씩), 먼저 인물 기준 그림 한 장(나란히 선 전신).
- 카드별 지시문(한국어 틀 + 영어 장면): `NN번 카드: <장면>. 인물: <그 장면 인물 생김새>. 구도: <레이아웃별>. 비율 <가로 16:9 | 4:5 | 1:1 …>.` 카드 비율은 그림 자리 모양에서 고른다(Canva 비율 매핑 재사용).
- 붙여넣기: Gemini에서 「이미지 복사」 후 앱에서 Ctrl+V/⌘V → 고른(또는 도우미에서 [붙여넣기]를 누른) 카드에 들어간다. 도우미 밖에서도 카드 편집 화면에 포커스가 글 칸이 아닐 때 붙여넣으면 선택된 카드에 들어간다(글 칸에 붙여넣는 글자는 그대로).
- 한꺼번에 올리기: 여러 파일을 고르면 파일의 수정 시각 순(같으면 이름 순)으로 그림 없는 카드에 차례로 배정하고, 순서 확인 화면에서 바꿀 수 있다.
- 인물 기준 그림: 도우미 안에 「Gemini가 그린 인물 기준 그림 올리기」(붙여넣기 지원) → `style.refImage`가 되어 Gemini·GPT 이미지에도 쓰인다.
- 출처 표시: `imgSource = 'gemini-app'`(배지 "Gemini 앱").
- 폰: 같은 화면(복사·올리기). 클립보드 이미지 붙여넣기는 되는 기기에서만.

### E. 그 밖의 결정(만드는 사람 몫으로 넘긴 것은 없음, 아래는 내 판단)

- 지시문 언어: 사용자가 읽고 고칠 수 있게 한국어 틀, 장면은 기존 영어 scene 사용.
- `world` 기본값은 시리즈 다음 회에 그대로 이어진다(ArtStyle 통째로 복사되므로).
- 사용량 기록: 연출 정리는 글 AI 사용량 태그 `direct`('연출 정리').
- 테스트: 프롬프트 함수(world 반영·Korean 문구·카드별 지시문·비율), 연출 정리 결과 적용(작가 수정 보호·sceneFor), 파일 배정 순서, 붙여넣기 대상 선택은 단위 테스트; 도우미 흐름·붙여넣기·후보는 브라우저 e2e(모의 응답).
