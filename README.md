# cardnovel · 카드소설 제작소

이야기를 넣으면 20장 카드소설(표지 1 · 본문 18 · 마지막 1)을 만들어 주는 개인용 웹앱(PWA).

- 기획 문서: [docs/PRD.md](docs/PRD.md) (원본은 Claude Docs 문서)
- 디자인(색·서체·카드 규격·테마 13종)은 기존 아티팩트 「카드소설 제작소」에서 그대로 옮겼다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run build
```

배포: https://cardnovel.vercel.app (Vercel 프로젝트 `cardnovel`). 정적 앱(`dist/`)과 Canva 연결용 서버리스 함수(`api/canva/*`)가 함께 올라간다. 홈 화면 설치·오프라인은 HTTPS(또는 localhost)에서만 동작한다.

### Canva 연결 설정

Canva 토큰(접근 토큰만 최대 4KB)은 압축·암호화해 `cn_t0`, `cn_t1`… 여러 쿠키로 나눠 담는다(브라우저는 쿠키 하나에 4KB까지만 저장). 로그인 뒤 돌아왔을 때 연결 정보가 실제로 저장됐는지 다시 확인한다.

| 위치 | 값 |
| --- | --- |
| Canva 개발자 포털 → Authorized redirects | `https://cardnovel.vercel.app/api/canva/callback` |
| Canva 개발자 포털 → Return navigation URL | `https://cardnovel.vercel.app/api/canva/return` |
| Canva 개발자 포털 → Scopes | `asset:read` `asset:write` `design:content:read` `design:content:write` `design:meta:read` |
| Vercel 환경 변수 | `CANVA_CLIENT_ID`, `CANVA_CLIENT_SECRET`, `CANVA_REDIRECT_URI`, `SESSION_SECRET` |

Canva 토큰은 `/api/canva` 경로에만 붙는 암호화된 HttpOnly 쿠키에 보관되며, 브라우저 스크립트나 다른 서버로 가지 않는다.

### 공유 링크 설정

「공유 링크 만들기」는 카드 20장을 JPEG로 Vercel Blob(공개 저장소 `cardnovel-shares`, 서울)에 올리고 `https://cardnovel.vercel.app/s/<id>` 주소의 넘겨 읽기 페이지를 만든다. 링크 미리보기(카톡·X 등)에는 표지가 뜨고, 검색 엔진에는 올라가지 않는다(noindex).

| 위치 | 값 |
| --- | --- |
| Vercel 환경 변수 | `BLOB_READ_WRITE_TOKEN`(Blob 저장소를 프로젝트에 연결하면 자동), `SHARE_KEY`(링크 만들기·지우기 권한) |
| 앱 설정 → 공유 링크 | `SHARE_KEY`와 같은 값을 한 번 넣는다 |

링크를 지우면 그림과 목록 파일이 모두 지워지고 주소는 「없거나 지워졌어요」를 보여 준다(엣지 캐시 때문에 최대 1분 늦을 수 있다).

### 구글 드라이브 백업 설정

브라우저만으로 동작하고 서버를 거치지 않는다. 권한은 앱이 만든 파일만 다루는 `drive.file` 하나다. 처음 한 번 Google Cloud에서 OAuth 클라이언트를 만든다. 같은 안내가 앱 「설정 → 연결」에 단계별로(지금 주소 복사 버튼, 자주 나는 오류 풀이 포함) 들어 있고, 클라이언트 보안 비밀번호처럼 잘못된 값을 넣으면 저장 전에 알려 준다.

1. https://console.cloud.google.com 에서 프로젝트를 하나 만든다(이름 예: cardnovel).
2. 「API 및 서비스 → 라이브러리」에서 **Google Drive API**를 사용 설정한다.
3. 「API 및 서비스 → OAuth 동의 화면」(Google Auth Platform → 브랜딩/대상): 사용자 유형 **외부**, 앱 이름·지원 이메일을 넣고, 「대상」에서 게시 상태를 **테스트**로 두고 **테스트 사용자**에 내 구글 계정을 추가한다. 범위(데이터 액세스)에 `.../auth/drive.file`을 넣는다.
4. 「사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID」: 유형 **웹 애플리케이션**, **승인된 자바스크립트 원본**에 `https://cardnovel.vercel.app` (다른 주소로도 쓰면 `https://3m-novel.vercel.app`, 개발용 `http://localhost:5173`)을 넣는다. 리디렉션 URI는 비워 둔다.
5. 만들어진 클라이언트 ID(`….apps.googleusercontent.com`)를 앱 「설정 → 연결」에 붙여 넣는다. 모든 기기에 기본으로 넣으려면 Vercel 환경 변수 `VITE_GOOGLE_CLIENT_ID`에 넣고 다시 배포한다(클라이언트 ID는 비밀이 아니다).

지금 배포(cardnovel.vercel.app)는 `VITE_GOOGLE_CLIENT_ID`가 설정돼 있고, 동의 화면이 **프로덕션**으로 게시돼 있다(사용자 유형 외부, 범위 `drive.file`만, 로고 없음 → 구글 심사 불필요). 그래서 누구나 설정 없이 「드라이브 연결」로 자기 드라이브에 백업할 수 있다. 브랜딩(홈페이지 `about.html`, 개인정보처리방침 `privacy.html`, 이용약관 `terms.html`)은 넣었지만 브랜드 확인은 하지 않아, 로그인 화면에는 앱 이름 대신 주소가 보일 수 있다.

작품 하나는 드라이브 `카드소설 제작소` 폴더에 `시리즈 N화 제목.cardnovel.json` 파일 하나(글·그림 포함)로 저장된다. 같은 작품을 다른 기기에서 고쳐 드라이브 쪽이 더 최신이면 덮어쓰기 전에 묻는다. 토큰은 1시간짜리라, 한 시간이 지나면 보관함에서 다시 「드라이브 연결」을 누른다. 데스크톱 앱에서는 구글이 로그인 창을 막을 수 있어 웹에서 쓰는 것을 권한다.

## 데스크톱 설치형 (macOS · Windows · Ubuntu)

`desktop/`은 배포된 앱(https://cardnovel.vercel.app)을 띄우는 Electron 앱이다. 웹을 고치면 설치형도 자동으로 최신이 되고, Canva 편집·로그인은 앱 창 안에서 열려 돌아오기가 앱 저장소로 바로 들어온다.

- 설치 파일은 GitHub Actions(`.github/workflows/desktop.yml`)가 세 OS에서 만든다. `desktop/`을 바꿔 푸시하면 빌드 후 `desktop-v<버전>` 릴리즈(https://github.com/doguri25/cardnovel/releases)에 설치 파일이 올라간다. 버전은 `desktop/package.json`에서 정한다.
- 파일: macOS(Apple Silicon만) `CardNovel-<버전>-mac-arm64.dmg`, Windows `CardNovel-<버전>-win-x64.exe`, Ubuntu `CardNovel-<버전>-linux-amd64.deb`·`-linux-x86_64.AppImage`
- 설치된 앱 파일 이름은 영문 `CardNovel`이다(맥에서 한글 앱 파일 이름은 패키징한 앱이 실행 직후 꺼지는 문제가 있어서). 창 제목·메뉴·Dock·바로 가기 이름은 「카드소설 제작소」이고, 작품·키가 저장되는 폴더 이름도 그대로다.
- CI가 세 OS에서 설치 파일을 만든 뒤 각 OS에서 한 번씩 실행해 20장 화면이 뜨는지 확인한다(맥은 dmg에서 꺼낸 앱으로).
- 개발자 서명이 없어 처음 열 때 경고가 뜬다. 맥: 「열리지 않음」 창에서 「완료」 → 시스템 설정 → 개인정보 보호 및 보안 → 「그래도 열기」(「손상되었기 때문에…」가 뜨면 터미널에서 `xattr -cr /Applications/CardNovel.app`). 윈도우: 「추가 정보」 → 「실행」.
- 데스크톱 앱의 작품·키 저장소는 브라우저와 따로다. 옮기려면 보관함의 「내보내기」/「가져오기」를 쓴다.

```bash
cd desktop && npm install && npm start
```

| 글자 세부 조정 | `*말*`로 감싼 부분은 강조색, 카드마다 글자 크기(작게~아주 크게)·글 위치(위·가운데·아래) |
| 내 테마·워터마크 | 배경 두 색·글자·강조색·서체·장식으로 테마를 만들어 저장(대비 경고, 미리보기). 로고 그림이나 핸들 글자를 카드 구석에(위치·크기·진하기·넣을 카드) |
| 시리즈 설정집 | 인물·장소·바뀌면 안 되는 사실·떡밥(풂/안 풂)을 시리즈마다 저장. AI로 채우기, 이번 회 설정 충돌 검사와 「이 문장으로 바꾸기」. 카드 구성 때 AI에 함께 보냄 |
| Canva 마감 | 20장을 「배경 그림 + 살아 있는 글자 상자」 파워포인트로 만들어 Canva로 가져가(URL 가져오기) 손본 뒤, 돌아가기(Return)를 누르면 20쪽을 받아 마감본으로 씀. 마감본은 미리보기·ZIP·공유·영상·링크 모두에 쓰이고 끌 수 있음 |

Canva 마감은 `api/canva/finish-upload`(파일을 Vercel Blob에 바로 올리는 토큰), `finish-import`(Canva URL 가져오기, 끝나면 올린 파일 삭제), `finish-export`(쪽마다 JPG), `page`(내보낸 쪽 전달)를 쓴다. Canva가 글꼴을 바꾸거나 글 상자 위치가 조금 달라질 수 있어 Canva에서 한 번 확인하는 단계로 쓴다.

| 최적화 | 고치는 카드를 먼저 그리고 바뀐 썸네일만 다시 그림, 보관함 썸네일은 표지가 바뀔 때만, 그림 많은 작품은 자동 저장 간격을 늘림, 서비스 워커가 빌드의 모든 파일을 미리 저장(오프라인에서 영상·Canva 기능까지)하고 배포마다 캐시 교체, 오프라인 다시 열기 버그 수정, 저장 공간 보존 요청·사용량 표시, 대화창 접근성(포커스 가두기·되돌리기), ←/→ 카드 이동, Ctrl/⌘+S 저장, 예기치 못한 오류 안내 |

### 자동 업데이트 (데스크톱 0.3.0부터)

- 데스크톱: `desktop/updater.js`가 켜고 8초 뒤와 6시간마다 최신 릴리즈의 `latest.json`(CI가 `desktop/scripts/manifest.js`로 버전·설치 파일·SHA-256을 적어 올림, `releases/latest/download/latest.json`이라 GitHub API 요청 한도와 무관)을 읽어, 이 컴퓨터용 설치 파일(맥 dmg / 윈도우 exe / AppImage / deb)이 더 새 버전이면 묻고 받아 SHA-256을 확인한 뒤 설치한다. 윈도우는 NSIS를 `--updated /S --force-run`으로, 맥은 dmg에서 앱을 꺼내 응용 프로그램 폴더의 앱과 바꾸는 스크립트로(Apple 서명이 없어 시스템 업데이터를 못 씀), AppImage는 파일 교체, deb는 `pkexec apt-get install`. 「자동으로」를 고르면 받아 두었다가 앱을 닫을 때 설치. 버전 비교·파일 고르기는 `desktop/update-core.js`(`npm test`), CI는 방금 만든 설치 파일로 가짜 9.9.9 매니페스트를 띄우고 패키징한 앱으로 `--update-check-only`를 돌려 「더 새 버전 · 이 컴퓨터용 파일 · 체크섬 있음」을 확인.
- 웹: 배포마다 서비스 워커 버전이 바뀐다. 새 버전이 자리를 잡으면 「지금 적용」 막대를 띄우고, 탭이 뒤로 가 있고 진행 중인 작업이 없으면 스스로 새로고침. 이전 버전의 캐시를 하나 남겨, 아직 바뀌지 않은 화면이 영상·Canva 기능을 열 수 있게 한다.

### 다섯 번째로 넣은 것 (데스크톱 0.3.1과 함께)

| 기능 | 내용 |
| --- | --- |
| 일괄 교정 | 「Ⅲ AI 평가」 아래 「일괄 교정」. 표지 제목·훅, 본문·소제목, 마지막 장, 캡션을 한 번에 글 AI에 보내 맞춤법·띄어쓰기·문장부호(선택: 하다체/해요체로 말투 통일)만 고침. 카드마다 바뀐 낱말을 지운 줄·밑줄로 보여 주고 고친 이유를 적음. 「적용」/「원래대로」, 「남은 n곳 모두 적용」(버전 「일괄 교정 적용 전」을 남기고 되돌리기 한 번에 돌아감). *강조* 표시는 지키고, 빠지면 되살리거나 알림. 길이가 크게 바뀐 답(고쳐 쓰기)은 버림. 교정한 뒤 글이 바뀐 카드는 적용하지 않음 |
| AI 낭독 릴스 | 릴스 창 「AI 낭독 넣기」: GPT(`/v1/audio/speech`, gpt-4o-mini-tts·tts-1)나 Gemini(TTS 모델, 오디오 응답) 목소리로 카드마다 읽고, 카드는 낭독이 끝날 때까지 머묾. 목소리·읽는 느낌(차분·긴장·따뜻·담담·대사 연기)·빠르기, 마지막 장 팔로우 문구 읽기, 「지금 카드 미리 듣기」, 읽을 글자 수와 예상 비용. 만든 낭독은 이 세션 동안 다시 쓰므로 넘김 효과·음악만 바꿔 다시 만들면 비용 없음. 배경음은 읽는 동안 30%로 낮아짐. 비용은 1,000자당 가격(설정에서 바꿈)으로 사용량에 「AI 낭독」으로 기록 |
| 게시 기록 · 성과 | 내보내기 「게시 기록 · 성과」. 작품마다 올린 시각·어디에(게시물/릴스/다른 곳)·링크·도달·좋아요·댓글·저장·공유·팔로우·메모, 참여율 바로 계산. 「성과 한눈에」는 모든 작품을 모아 평균 참여율(도달을 넣은 게시물이 절반 미만이면 반응 점수), 반응 좋은 순 표(제목 누르면 그 작품 열기), 테마·표지 모양·요일·시간대·올린 곳별 막대, CSV, 「AI 패턴 읽기」(패턴·다음 화 제안·표지 제안). AI 평가는 다른 작품들의 반응 좋았던/약했던 표지를 함께 보고 훅 점수와 제목 후보를 냄 |

### 여섯 번째로 넣은 것 (화면 정리와 올리기 전 도구)

| 기능 | 내용 |
| --- | --- |
| 단계 탭 | 컴퓨터에서도 왼쪽은 「Ⅰ 이야기 · Ⅱ 카드 · Ⅲ 다듬기(평가·교정)」, 오른쪽 미리보기 아래는 「꾸미기 · 내보내기」 중 하나만 보여 줌. 탭마다 짧은 상태(구성함, 글 n/18 · 그림 n/19, 평가 점수), 내보내기 탭에는 점검에서 확인할 것 개수. 카드로 만들면 카드 탭으로, 마지막 탭은 다시 열 때 그대로. 폰은 아래 다섯 탭(평가 → 다듬기) |
| 간단한 카드 칸 | 카드마다 글과 그림 버튼만 보이고, 배치·글자 크기·글 위치·그림 자르기·머리말·강조·소제목은 「디자인」을 눌러 펼침. 접혀 있어도 바꾼 값(예: 대사 · 글자 크게)을 옆에 보여 줌. 「디자인 칸 모두 펼치기」로 전부 열어 둘 수 있음 |

| 내보내기 정리 | 저장(형식 · 전체 ZIP · 이 카드만) / 올리기(인스타 공유 · 캡션·해시태그 · 미리보기 · 릴스 · 공유 링크) / 마감·기록(Canva · 게시 기록) 세 묶음 |

## API 키

키는 이 기기의 브라우저(IndexedDB)에만 저장되고 각 AI 회사 API로만 전송된다. 공용 기기에서는 쓰지 말고, 각 회사 콘솔에서 월 사용 한도를 걸어 두는 것을 권한다.
