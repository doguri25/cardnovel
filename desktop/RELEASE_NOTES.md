카드소설 제작소 데스크톱 설치 파일입니다. 앱은 https://cardnovel.vercel.app 을 띄우므로 웹이 바뀌면 자동으로 최신이 됩니다. 처음 열 때만 인터넷이 필요합니다.

## 0.3.2에서 새로워진 것

0.3.0·0.3.1을 쓰고 있으면 앱이 이 버전을 알아서 알려 줍니다. 데스크톱 껍데기는 그대로이고, 아래 기능은 웹 앱(https://cardnovel.vercel.app)에 들어가 있어 브라우저에서도 바로 쓸 수 있습니다.

**화면 정리**
- **단계 탭**: 왼쪽은 「이야기 · 카드 · 다듬기(평가·교정)」, 미리보기 아래는 「꾸미기 · 내보내기」 중 하나만 보여 줍니다. 탭에 진행 상태(글 n/18 · 그림 n/19, 평가 점수)가 붙습니다.
- **간단한 카드 칸**: 카드마다 글과 그림 버튼만 보이고, 배치·글자 크기·글 위치·머리말·강조·소제목은 「디자인」을 눌러 펼칩니다. 「디자인 칸 모두 펼치기」로 예전처럼 볼 수 있습니다.
- **내보내기**: 「저장 / 올리기 / 마감·기록」 세 묶음으로 정리했습니다.

**새 도구**
- **게시 전 점검**: 빈 카드, 너무 긴 카드, 짝 안 맞는 별표, 그림 없는 카드, 캡션·해시태그 한도 등을 「꼭 확인 / 확인 / 참고」로 보여 주고 바로 그 카드로 데려갑니다.
- **캡션 · 해시태그**: 캡션과 해시태그를 고치고 「더 보기」 전까지 보이는 부분을 미리 보며, AI 제안과 반응 좋았던 해시태그를 골라 넣습니다.
- **되돌리기 알림**, **미리보기를 눌러 글 고치기 · 작은 카드 끌어서 순서 바꾸기**, **보관함 검색(초성도)·정렬·30일 휴지통**, **설정 탭**, **빠른 실행(Ctrl+K · ⌘K)**.

**고친 것**
- **Canva에 연결해도 「먼저 연결해 주세요」가 뜨던 문제**: Canva 로그인 정보가 브라우저 쿠키 한도(4KB)를 넘어 저장되지 않던 것을 나눠 담도록 고쳤습니다. 한 번 더 「Canva 연결하기」를 눌러 주세요.
- **구글 드라이브 백업**: 이제 설정 없이 「보관함 → 드라이브 연결」만 누르면 자기 구글 계정의 드라이브에 백업됩니다. 직접 만든 클라이언트 ID를 쓰고 싶으면 「설정 → 연결」에 단계별 안내가 있습니다.
- 앱 소개 · 개인정보처리방침 · 이용약관 페이지를 추가했습니다(설정 아래 링크).

## 받을 파일

| 운영체제 | 받을 파일 |
| --- | --- |
| macOS (Apple Silicon, M1 이후) | `CardNovel-*-mac-arm64.dmg` |
| Windows | `CardNovel-*-win-x64.exe` |
| Ubuntu | `CardNovel-*-linux-amd64.deb` 또는 `CardNovel-*-linux-x86_64.AppImage` |

## 처음 열 때 경고가 뜹니다 (Apple·Microsoft 개발자 서명이 없어서입니다)
- macOS: dmg를 열고 `CardNovel`을 응용 프로그램 폴더로 끌어 넣습니다. 처음 열면 「열리지 않음」 창이 뜨면 「완료」를 누르고, 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 「그래도 열기」 → 암호 입력 → 다시 「그래도 열기」. 한 번만 하면 됩니다.
- macOS에서 「손상되었기 때문에 열 수 없습니다」가 뜨면 터미널에서 `xattr -cr /Applications/CardNovel.app` 을 실행한 뒤 다시 엽니다.
- Windows: 'Windows의 PC 보호' 창에서 「추가 정보」 → 「실행」.
- Ubuntu: `.deb`는 더블클릭하거나 `sudo apt install ./CardNovel-*-linux-amd64.deb`. AppImage는 실행 권한을 준 뒤 실행.

데스크톱 앱의 작품과 API 키는 브라우저와 따로 저장됩니다. 옮기려면 보관함의 「내보내기」 → 「가져오기」나 구글 드라이브 백업을 쓰세요.
