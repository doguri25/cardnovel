카드소설 제작소 데스크톱 설치 파일입니다. 앱은 https://cardnovel.vercel.app 을 띄우므로 웹이 바뀌면 자동으로 최신이 됩니다. 처음 열 때만 인터넷이 필요합니다.

## 0.3.3에서 새로워진 것

0.3.x를 쓰고 있으면 앱이 이 버전을 알아서 알려 줍니다. 데스크톱 껍데기는 그대로이고, 아래 기능은 웹 앱(https://cardnovel.vercel.app)에 들어가 있어 브라우저에서도 바로 쓸 수 있습니다.

**Canva AI로 자동 그리기**
- 그림 AI에서 **「Canva AI (자동)」**을 고르면 연결한 Canva 계정의 Canva AI가 카드 그림을 그립니다. 「모든 그림 그리기」, 카드마다 「AI 그림」, 표지 후보 3장 모두 됩니다.
- 이 앱이 따로 돈을 쓰지 않고 Canva 계정의 AI 사용량이 장마다 차감됩니다. 지금 사용량(%)을 상태 줄에 보여 주고, 한도에 닿으면 멈춥니다.
- 장면을 맨 앞에 두고 그 장면에 나오는 인물의 생김새만 붙여 보내, 그림이 카드 장면을 잘 따릅니다. 세 장씩 동시에 그려 빠릅니다.

**그림이 지금 카드 글을 따라갑니다**
- 「카드로 만들기」 뒤에 카드 글이 많이 바뀌었으면, 그리기 직전에 그 카드들의 그림 장면을 글 AI가 한 번에 다시 씁니다(모든 그림 AI).
- 카드의 「디자인」에서 **「그릴 장면」**을 보고 직접 고칠 수 있습니다.
- 「모든 그림 그리기」에서 실패한 카드는 **「빠진 N장 다시 그리기」**로 그것만 다시 그립니다. 처음 세 장이 모두 실패하면 이유를 보여 주고 멈춥니다.

**다듬기에서 바로 비교**
- 「AI 평가」의 고칠 카드나 「일괄 교정」의 고친 곳을 누르면, 옆 미리보기가 그 카드로 바로 바뀌어 제안과 지금 카드를 나란히 볼 수 있습니다. 「이 문장으로 바꾸기」를 누르면 바뀐 모습이 바로 보입니다.
- 카드 글을 직접 고치려면 **「카드에서 고치기」**를 누릅니다.

**고친 것**
- 새 Claude 모델(Opus 5.5·Sonnet 5.5 등)로 카드를 만들 때 「요청이 받아들여지지 않았어요 (tool_choice …)」 오류가 나던 문제를 고쳤습니다.
- 「설정 → 연결」에서 구글 드라이브를 바로 연결할 수 있습니다.

## 받을 파일

| 운영체제 | 받을 파일 |
| --- | --- |
| macOS (Apple Silicon, M1 이후) | `CardNovel-*-mac-arm64.dmg` |
| Windows | `CardNovel-*-win-x64.exe` |
| Ubuntu | `CardNovel-*-linux-amd64.deb` 또는 `CardNovel-*-linux-x86_64.AppImage` |

## 처음 열 때 경고가 뜹니다 (Apple·Microsoft 개발자 서명이 없어서입니다)
- macOS: dmg를 열고 `CardNovel`을 응용 프로그램 폴더로 끌어 넣습니다. 처음 열면 「열리지 않음」 창이 뜨면 「완료」를 누르고, 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 「그래도 열기」 → 암호 입력 → 다시 「그래도 열기」. 한 번만 하면 됩니다.
- macOS에서 「손상되었기 때문에 열 수 없습니다」가 뜨면 터미널에서 `xattr -cr /Applications/CardNovel.app` 을 실행한 뒤 다시 엽니다.
- Windows: 'Windows의 PC 보호' 창에서 「추가 정보」 → 「실행」.
- Ubuntu: `.deb`는 더블클릭하거나 `sudo apt install ./CardNovel-*-linux-amd64.deb`. AppImage는 실행 권한을 준 뒤 실행.

데스크톱 앱의 작품과 API 키는 브라우저와 따로 저장됩니다. 옮기려면 보관함의 「내보내기」 → 「가져오기」나 구글 드라이브 백업을 쓰세요.
