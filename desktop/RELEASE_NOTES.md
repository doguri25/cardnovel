## 0.3.0에서 새로워진 것

**자동 업데이트**
- **데스크톱 앱이 스스로 업데이트됩니다.** 켜고 조금 뒤와 6시간마다 GitHub 릴리즈를 확인해, 새 버전이 있으면 「지금 업데이트 / 나중에 / 이 버전 건너뛰기」를 묻습니다. 「다음부터는 묻지 않고 자동으로 업데이트」를 켜면 조용히 받아 두었다가 앱을 닫을 때 바꿉니다. 메뉴 「도움말 → 업데이트 확인…」으로 바로 확인할 수도 있습니다.
- 받은 파일은 GitHub가 알려 주는 SHA-256과 맞는지 확인한 뒤에만 설치합니다.
- Windows는 설치 프로그램이 조용히 덮어쓰고 다시 켭니다. macOS는 응용 프로그램 폴더의 앱을 새 앱으로 바꿔 다시 켭니다(dmg에서 바로 실행 중이면 dmg를 열어 줍니다). Ubuntu는 AppImage가 스스로 바뀌고, .deb는 비밀번호를 물은 뒤 설치합니다.
- **웹 앱도** 새로 배포되면 「새 버전이 나왔어요 · 지금 적용」을 띄우고, 다른 창을 보고 있는 동안 작업 중이 아니면 알아서 새 버전으로 바뀝니다. 바뀌기 전에도 열려 있던 화면의 기능(릴스 영상, Canva 마감)은 그대로 열립니다.
- 설정 아래쪽에 앱 빌드 시각이 나옵니다.

**0.3.0으로 한 번은 직접 바꿔 주세요.** 0.2.0 이하에는 업데이트 기능이 없어서, 이 버전을 받아 설치하면 그다음부터 자동으로 바뀝니다.

## 받을 파일

| 운영체제 | 받을 파일 |
| --- | --- |
| macOS (Apple Silicon, M1 이후) | `CardNovel-*-mac-arm64.dmg` |
| Windows | `CardNovel-*-win-x64.exe` |
| Ubuntu | `CardNovel-*-linux-amd64.deb` 또는 `CardNovel-*-linux-x86_64.AppImage` |

## 처음 열 때 경고가 뜹니다 (Apple·Microsoft 개발자 서명이 없어서입니다)
- macOS: dmg를 열고 `CardNovel`을 응용 프로그램 폴더로 끌어 넣습니다. 처음 열면 「열리지 않음」 창이 뜨면 「완료」를 누르고, 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 「그래도 열기」 → 암호 입력 → 다시 「그래도 열기」. 한 번만 하면 됩니다.
- macOS에서 「손상되었기 때문에 열 수 없습니다」가 뜨면 터미널에서 `xattr -cr /Applications/CardNovel.app` 을 실행한 뒤 다시 엽니다.
- Windows: 'Windows의 PC 보호' 창에서 「추가 정보」 → 「실행」.
- Ubuntu: `.deb`는 더블클릭하거나 `sudo apt install ./CardNovel-*-linux-amd64.deb`. AppImage는 실행 권한을 준 뒤 실행.

데스크톱 앱의 작품과 API 키는 브라우저와 따로 저장됩니다. 옮기려면 보관함의 「내보내기」 → 「가져오기」나 구글 드라이브 백업을 쓰세요.
