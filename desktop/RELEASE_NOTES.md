카드소설 제작소 데스크톱 설치 파일입니다. 앱은 https://cardnovel.vercel.app 을 띄우므로 웹이 바뀌면 자동으로 최신이 됩니다. 처음 열 때만 인터넷이 필요합니다.

## 0.3.4에서 새로워진 것

0.3.x를 쓰고 있으면 앱이 이 버전을 알아서 알려 줍니다. 이번 버전은 버그와 보안 문제를 한꺼번에 고쳤습니다(여러 AI 에이전트가 앱 전체를 나눠 살펴보고, 다른 에이전트가 하나하나 다시 확인한 26건). 대부분은 웹 앱에 들어가 있어 브라우저에서도 바로 적용됩니다.

**보안**
- 조작된 링크로 앱 안에 저장된 AI 키를 빼 갈 수 있던 구멍을 막았습니다(Canva 그림 전달 경로가 그림 파일만, 안전한 방식으로 넘깁니다).
- 다른 기기에서 가져온 작품 파일로 화면에 코드를 끼워 넣을 수 없게 했습니다.
- 데스크톱: 업데이트 파일을 공용 임시 폴더가 아닌 이 사용자만 쓰는 폴더에 받고, 웹·메일 링크가 아닌 주소는 열지 않습니다.

**작업이 사라지지 않게**
- 「모든 그림 그리기」나 「카드로 만들기」 중에 다른 작품을 열어도, 결과는 원래 작품에 들어갑니다(다른 작품을 덮어쓰지 않음).
- 가져온 작품에서 「되돌리기」를 누르면 카드가 비던 문제, 알림의 「되돌리기」가 다른 변경을 되돌리던 문제를 고쳤습니다.
- 구글 드라이브: 두 기기에서 모두 고친 작품을 덮어쓰지 않고 먼저 물어봅니다.
- 캡션·해시태그·디자인만 바꿨을 때도 버전 기록이 남습니다. 휴지통 비우기가 같은 작품의 버전 기록을 지우지 않습니다.
- 저장이 실패하면 「자동 저장됨」 대신 실패를 알립니다.

**그 밖에**
- Canva 작업이 실패해도 Canva 연결이 끊기지 않고, 연결이 정말 끝났을 때는 다시 연결하라고 알려 줍니다.
- 카드 순서를 바꾼 뒤에도 AI 평가 제안과 그림 장면이 맞는 카드에 들어갑니다. 일괄 교정이 강조 표시(*)를 엉뚱한 단어에 다시 붙이지 않습니다.
- 창 안에서 글자를 고르다 바깥에서 손을 떼도 창이 닫히지 않습니다. 평가·교정·공유 링크 만들기 중에는 자동 업데이트가 기다립니다.
- 짧은 AI 작업(마지막 장 한 줄, 다시 쓰기 등)이 생각이 긴 모델에서 끊기면 한 번 더 넉넉하게 시도합니다. OpenAI 크레딧이 없을 때는 기다리지 않고 바로 알려 줍니다.

## 받을 파일

| 운영체제 | 받을 파일 |
| --- | --- |
| macOS (Apple Silicon, M1 이후) | `CardNovel-*-mac-arm64.dmg` |
| Windows | `CardNovel-*-win-x64.exe` |
| Ubuntu | `CardNovel-*-linux-amd64.deb` 또는 `CardNovel-*-linux-x86_64.AppImage` |

## 처음 열 때 경고가 뜹니다 (Apple·Microsoft 개발자 서명이 없어서입니다)
- macOS: dmg를 열고 `CardNovel`을 응용 프로그램 폴더로 끌어 넣습니다. 처음 열면 「열리지 않음」 창이 뜨면 「완료」를 누르고, 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 「그래도 열기」 → 암호 입력 → 다시 「그래도 열기」. 한 번만 하면 됩니다.
- macOS에서 「손상되었기 때문에 열 수 없습니다」가 뜨면 터미널에서 `xattr -cr /Applications/CardNovel.app` 을 실행한 뒤 다시 엽니다.
- Windows: 'Windows의 PC 보호' 창에서 「추가 정보」 → 「실행」.
- Ubuntu: `.deb`는 더블클릭하거나 `sudo apt install ./CardNovel-*-linux-amd64.deb`. AppImage는 실행 권한을 준 뒤 실행.

데스크톱 앱의 작품과 API 키는 브라우저와 따로 저장됩니다. 옮기려면 보관함의 「내보내기」 → 「가져오기」나 구글 드라이브 백업을 쓰세요.
